Complete reference for the GatePilot Reverse-Proxy API Gateway

Getting Started

Welcome to GatePilot. GatePilot sits between your clients and your backend microservices, providing secure API key authentication, tenant-specific rate limiting, async request logging, and webhooks.

💡
Base URL: http://localhost:3000
All API requests must be made over HTTPS in production environments.

Authentication

GatePilot uses two different types of authentication depending on the endpoint you are accessing.

Gateway Proxy Auth

Requests made to the /api/proxy/* routes require an API key in the headers.

HTTP Header
x-api-key: gp_a1b2c3d4e5f6g7h8...

Admin API Auth

Requests made to manage tenants, keys, and view analytics require the admin token.

HTTP Header
x-admin-token: dev_admin_token

Rate Limits & Headers

GatePilot enforces sliding-window rate limits per API key using Redis. When a request is made, the following HTTP headers are included in the response:

  • X-RateLimit-Limit: The maximum number of requests allowed in the current window.
  • X-RateLimit-Remaining: The number of requests remaining in the current window.
  • X-RateLimit-Reset: The Unix timestamp when the rate limit window resets.

If you exceed the rate limit, the API will return a 429 Too Many Requests status code.

Reverse Proxy

The core feature of GatePilot. All requests to this endpoint are authenticated, rate-limited, logged, and then forwarded to the target backend service.

ALL /api/proxy/*

Appends the wild-card path to the configured TARGET_BASE_URL and forwards the request method, body, and query parameters.

Example Request
curl -X GET "http://localhost:3000/api/proxy/products" \
  -H "x-api-key: gp_abc123"

package main

import (
    "fmt"
    "net/http"
    "io/ioutil"
)

func main() {
    client := &http.Client{}
    req, _ := http.NewRequest("GET", "http://localhost:3000/api/proxy/products", nil)
    req.Header.Add("x-api-key", "gp_your_api_key_here")

    resp, _ := client.Do(req)
    defer resp.Body.Close()
    body, _ := ioutil.ReadAll(resp.Body)
    
    fmt.Println(string(body))
}
use reqwest::header;

#[tokio::main]
async fn main() -> Result<(), Box> {
    let mut headers = header::HeaderMap::new();
    headers.insert("x-api-key", header::HeaderValue::from_static("gp_your_api_key_here"));

    let client = reqwest::Client::new();
    let res = client.get("http://localhost:3000/api/proxy/products")
        .headers(headers)
        .send()
        .await?
        .text()
        .await?;

    println!("{}", res);
    Ok(())
}
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class Main {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("http://localhost:3000/api/proxy/products"))
            .header("x-api-key", "gp_your_api_key_here")
            .GET()
            .build();

        HttpResponse response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}
